# NUPTIA — V3 Complète

Plateforme d’invitations numériques et de gestion des mariages.
Slogan : « Chaque union mérite une belle invitation. »

## Nouveautés de la V3
1. **Sélection de musique depuis le téléphone** (fichier audio local ou lien direct MP3, avec téléversement cloud lorsque Supabase est connecté).
2. **Google Maps et coordonnées GPS** (latitude/longitude avec génération automatique d'itinéraire + lien direct).
3. **Dress code avec cases à cocher** (choix multiples prédéfinis + précision personnalisée).
4. **Suppression des espaces de mariage avec confirmation** sécurisée.
5. **Statistiques détaillées et rapports** (taux de confirmation, places totales/attribuées/restantes, export CSV).
6. **Plan visuel de la salle** (vue interactive des tables, capacité et occupation).
7. **Livre de félicitations** (messages des invités visibles et modérables).
8. **Synchronisation en ligne & sauvegarde sécurisée (Supabase)** : connexion organisateur, synchronisation multi-téléphones, stockage médias et export/import de sauvegarde JSON.

## Installation sur GitHub Pages
1. Dans votre dépôt GitHub (`theuriet/nuptia`), remplacez `index.html` et `README.md` par les nouveaux codes.
2. Pour activer la synchronisation en ligne entre plusieurs téléphones, renseignez votre **URL Supabase** et votre **clé publique (anon)** dans l'onglet **Sync & Sécurité** de l'application (après avoir exécuté le script SQL indiqué).
